## Findings before correction

48 of 53 source files matched exactly after normalizing line endings. Two URL files differed only in line wrapping, and the review migration differed in generated metadata/import/dependency ordering with equivalent operations. The two substantive source differences were the MySQL settings and PyMySQL startup import.

The machine's default Python was 3.14 with Django 4.2.30. The bundled SQLite database had four movies but lacked the review, order, and item migrations. The remote web app had no virtualenv selected. The existing virtualenv did contain Django 5.0. The remote error log showed an import error under the system Python environment. Static mapping existed; media mapping was missing.

## Corrections and explicit differences

The app is functionally aligned with the final tutorial, but the complete deliverable is **not byte-for-byte identical** to the book. These differences are intentional and reviewable:

1. Restored SQLite and removed the PyMySQL import to match the publisher's final code.
2. Pinned Django 5.0 and Pillow; used compatible isolated Python environments.
3. Added Chapter 13's `STATIC_ROOT` and the actual PythonAnywhere WSGI configuration.
4. Used explicit allowed hosts and a unique untracked secret key. The live WSGI sets debug off, HTTPS redirects, and secure session/CSRF cookies rather than exposing the tutorial's development settings.
5. Defined `LOGIN_URL='accounts.login'` so login-required redirects resolve to the actual route.
6. Added repeatable catalog seeding, setup documentation, and 15 workflow and reporting tests.
7. Removed generated bytecode and mutable database files from Git tracking while preserving local data. The ZIP includes a separate clean migrated demonstration database.
8. Retained harmless URL wrapping and generated migration metadata differences; they do not change routing or schema behavior.

The reporting extension adds Review.is_hidden, a ReviewReport model, an authenticated report form, and permission-checked admin moderation. Reports immediately hide reviews; staff can uphold the report or restore the review. Existing review URLs now validate their movie association. About copy describes the real educational app, and its image fits mobile/tablet widths. These are intentional differences from the textbook needed for the supplied requirements. No streaming service or payment gateway has been added.
